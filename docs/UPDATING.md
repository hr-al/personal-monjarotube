# Обновление без потери входа и настроек

1. Скачайте `MonjaroTube-1.0.0.apk` из [официального выпуска](https://github.com/hr-al/personal-monjarotube/releases/latest).
2. Закройте MonjaroTube и откройте APK на ГУ. Если Android запросит разрешение установки из выбранного источника, разрешите установку для этого источника.
3. Выберите **«Обновить»**. **Не удаляйте предыдущую версию, не очищайте данные или хранилище приложения.**
4. Откройте приложение и проверьте «Настройки → Приложение»: версия 1.0.0. Проверьте профиль YouTube, подписки, выбранные режим обхода и вариант входа, поиск и воспроизведение.

Идентификатор `ru.geelymonjaro.monjarotube` сохранён. Версия 1.0.0 имеет versionCode 12, выше 11 у 0.2.5. Релиз подписан тем же сертификатом, что и ранее распространённая тестовая сборка 0.2.5. Отличается тип сборки: в релизе отключены Android debuggable и отладка WebView.

Ожидаемый SHA-256 сертификата подписи:

```text
7416b51373bb20438b5da68d32ae20dec9e67a456315084f892e373c48ad8e7c
```

Это публичный отпечаток сертификата, не секретный ключ и не SHA-256 APK. Контрольная сумма конкретного APK находится в файле `.sha256` рядом с ним в выпуске.

Настройки хранятся в прежнем файле SharedPreferences `dpi`, с прежними именами параметров. Хранилище WebView и cookies не удаляются и не переносятся. Сервер Google по собственной политике может потребовать повторный вход; обновление приложения не может гарантировать бессрочную действительность сессии.

Если Android предлагает удалить старую версию или сообщает о несовместимой подписи — **остановитесь и сохраните установленную версию**. Не удаляйте приложение для обхода этой ошибки. Убедитесь, что APK скачан из официального выпуска. Самостоятельные сборки других авторов могут иметь иной сертификат и не подходят для обновления официальной установки.

## Проверка будущих версий

Откройте **«Настройки → Приложение → Проверить обновления»**. Приложение запрашивает последний стабильный GitHub Release. Черновики и предварительные выпуски не предлагаются. Сравнение версий числовое: например, 1.10.0 новее 1.9.0.

При наличии новой версии можно открыть APK или страницу выпуска в системном браузере. Установка выполняется обычным установщиком Android по вашему действию. Если браузера нет, приложение предложит скопировать ссылку и скачать APK на другом устройстве.

Запрос проверки — отдельное прямое HTTPS-соединение с api.github.com. Cookies YouTube и данные аккаунта в него не передаются. Встроенный обход для YouTube не перенастраивается. Проверка запускается только по нажатию, без фонового опроса. При недоступности GitHub выводится ошибка проверки; это не означает отсутствие обновлений и не мешает просмотру видео.
