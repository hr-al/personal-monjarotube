# Сборка

Требуются JDK 21 (компиляция исходников для Java 17), Android SDK Platform 36.1, Build Tools 36.1.0, NDK 28.2.13676358 и CMake 3.22.1. Gradle Wrapper 9.3.1 и Android Gradle Plugin 9.1.1 зафиксированы в проекте. Минимальная версия устройства — Android 11 / API 30. ABI: arm64-v8a, armeabi-v7a, x86_64.

Откройте корневую папку в Android Studio, настройте путь SDK локально. Не добавляйте `local.properties` в Git.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

На Windows используйте `gradlew.bat`. Самостоятельная debug-сборка подписывается вашим локальным debug-ключом и обычно несовместима по подписи с официальным APK.

## Подписанный релиз

Перед сборкой задайте переменные среды:

| Переменная | Значение |
|---|---|
| `MONJAROTUBE_KEYSTORE_FILE` | Абсолютный путь к закрытому keystore |
| `MONJAROTUBE_STORE_PASSWORD` | Пароль хранилища |
| `MONJAROTUBE_KEY_ALIAS` | Псевдоним ключа |
| `MONJAROTUBE_KEY_PASSWORD` | Пароль ключа |

```sh
./gradlew :app:assembleRelease :app:testDebugUnitTest :app:lintRelease
```

Без переменных сборка release остаётся неподписанной и не предназначена для установки. Закрытый ключ, пароли, файлы `.p12`, `.jks`, `.keystore` и конфигурация подписи в репозиторий не входят. Официальные выпуски сохраняют прежний сертификат для совместимости с установленными версиями; смена ключа требует отдельного плана миграции.

## Выпуск обновления

1. Увеличить `versionCode` и `versionName` в `app/build.gradle.kts`. Для стабильной версии использовать `X.Y.Z`.
2. Обновить CHANGELOG и пройти проверки. Инструментальные тесты, меняющие тестовое состояние, запускать только на отдельном эмуляторе.
3. Собрать release с официальным ключом, проверить `apksigner verify --print-certs`, отключённую отладку и установку поверх предыдущей версии с сохранением тестовых cookies и настроек.
4. Создать тег `vX.Y.Z` и GitHub Release с APK **`MonjaroTube-X.Y.Z.apk`** и соответствующим файлом `.sha256`. Опубликовать стабильный выпуск как Latest. Эти имена использует встроенная проверка обновлений.
5. Проверить на устройстве ответ «Проверить обновления». Не публиковать фиктивную повышенную версию для проверки кнопки скачивания: используйте тестовые данные.

GitHub Actions выполняет сборку и статические проверки без ключа официальной подписи. Артефакт CI — неподписанный release APK для проверки сборки, не официальный установочный файл.
