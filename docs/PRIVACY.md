# Данные и соединения

MonjaroTube отображает сайт YouTube в системном Android WebView. Авторизация проходит на страницах Google; сессия хранится в закрытом хранилище WebView на устройстве. YouTube и Google обрабатывают данные в соответствии со своими правилами.

Приложение хранит локально выбранные параметры обхода, настройки интерфейса и, при включённой опции, последнюю открытую страницу YouTube. Поисковый запрос может входить в URL последней страницы. Служебные URL завершения входа не сохраняются как стартовые страницы.

В проекте нет собственного сервера аккаунтов, аналитики или автоматической отправки журналов разработчику. Диагностика доступна пользователю вручную. Не публикуйте скриншоты форм входа, адрес электронной почты или полные служебные ссылки Google в Issues.

Для встроенного DNS приложение обращается по HTTPS к Cloudflare 1.1.1.1 / 1.0.0.1, с резервным системным DNS. Это не меняет DNS-настройки Android. Встроенный локальный SOCKS используется WebView приложения; MonjaroTube не создаёт системный VPN и не перенаправляет трафик остальных приложений.

По нажатию «Проверить обновления» выполняется HTTPS-запрос к публичному GitHub API. GitHub получает обычные сетевые сведения, включая IP и User-Agent с версией MonjaroTube. Данные аккаунта YouTube и cookies в запрос не добавляются. Скачивание APK открывается во внешнем браузере.
