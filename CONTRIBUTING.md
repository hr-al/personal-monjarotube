# Участие

Ошибки и результаты проверки других ГУ можно сообщать через Issues. Укажите устройство, Android, WebView, версию приложения, выбранный профиль и шаги воспроизведения. Проверенные устройства добавляются в README только с указанием результата проверки.

Для изменений кода откройте Pull Request и опишите итоговое поведение и проверку. Сохранение установленной сессии и настроек — обязательное требование: не меняйте applicationId, имена существующих настроек и хранилище WebView без плана миграции. Изменения обхода проверяйте отдельно для воспроизведения и входа.

Запускайте JVM-тесты и lint. Тесты, создающие тестовые cookies или меняющие настройки, выполняйте только на отдельном эмуляторе. Официальные ключи подписи в разработке и CI не используются.
