# Изменения

## 1.0.0

- Первый стабильный выпуск, основанный на проверенной версии 0.2.5.
- Проверка новых стабильных выпусков GitHub из меню «Приложение»; ссылка на скачивание APK и страницу выпуска.
- Открытый репозиторий personal-monjarotube, инструкции по установке, обновлению и сборке.
- Релизная сборка без отладки Android и WebView, с сохранением прежнего идентификатора и сертификата подписи.
- Сохранены механизм авторизации, варианты встроенного обхода, поиск и существующие настройки.

## 0.2.5

- Явный запрос экранной клавиатуры для веб-полей.
- Нативная форма поиска YouTube, доступная по лупе в верхней панели.

## 0.2.4

- Независимые варианты обхода для завершения входа Google.
- Восстановление после ошибки авторизации без удаления cookies.
- Проверка соединения с YouTube и обоими серверами входа.

## 0.2.0–0.2.3

- Автоматический запуск встроенного обхода.
- Нативное меню соединения, просмотра и приложения.
- Авторизация в текущем WebView; обновлённая иконка с белым фоном.
