# Сообщения о безопасности

Не публикуйте в Issues секреты, cookies, пароли, коды подтверждения и ссылки завершения входа. Сообщение об утечке данных или другой уязвимости можно отправить через GitHub **Security → Report a vulnerability**, если приватные сообщения включены для репозитория.

Скачивайте официальные APK только из Releases этого репозитория. Контрольная сумма APK публикуется рядом с файлом; постоянный отпечаток сертификата указан в docs/UPDATING.md. Самостоятельные сборки могут иметь другую подпись.
